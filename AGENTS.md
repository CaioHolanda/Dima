# Diretório de trabalho e versionamento

- Trabalhar exclusivamente em `C:\Codes\Dima` para este projeto.
- Não criar clones, cópias de revisão, diretórios de staging ou worktrees adicionais.
- Usar Git/GitHub para histórico e versionamento, preservando alterações locais existentes.
- Conferir branch, status e versão atual neste diretório antes de implementar ou validar alterações.
- Esta orientação explícita do usuário prevalece sobre sugestões genéricas de isolamento em cópias.
